## コンセプト

**「引き算の美と空白」**

情報を詰め込みすぎず、余白とタイポグラフィを活かしたシンプルな設計を心がけました。  
必要な情報に迷わずたどり着ける視認性を保ちつつ、カードを裏返すギミックや立体的なUIなど、触れて心地よいインタラクションを取り入れています。

---

## 主な機能・実装のこだわり

フレームワークに頼らず、素の **HTML / CSS / JavaScript** のみで一から設計・実装しました。

* **ダーク / ライトモード切り替え**: CSS変数を用いたテーマ管理により、目に優しい配色切り替えを実現。
* **インタラクティブな自己紹介カード**: CSS 3D Transform（`perspective` / `rotateY`）を活用し、クリックでカードが裏返ってパーソナルな一面が見えるフリップUIを実装。
* **制作物ギャラリー（3Dリール & モーダル詳細表示）**: 作品を直感的に閲覧できるカルーセルと、`data-*` 属性を用いた詳細モーダル表示。
* **スクロール連動アニメーション**: `IntersectionObserver` を用いたパフォーマンスに配慮したフェードイン演出。
* **ワンクリック連絡先コピー**: Clipboard API を利用し、メールアドレスをワンクリックでコピーできる機能。
